## 記入時の注意

- GitHub URL の `[owner]`、`[repository]`、`[branch]` は remote と現在のブランチから解決する。プライベート URL を推測で公開情報として書かない。
- 既存の `<!-- BEGIN_TF_DOCS -->` と `<!-- END_TF_DOCS -->` の間は terraform-docs の管理領域。上のテンプレートはその外に置く。
- コスト表に固定費だけを置かない。利用量で変わる費用を別にし、前提が変われば試算も変わることを読める形にする。
- IAM、監視、障害対応は、テーマ内で実装したものだけを書く。テーマ外の事項を「次に作るもの」として列挙しない。
