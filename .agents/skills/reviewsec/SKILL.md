  # Google Cloudアーキテクチャのレビューするスキル
  アーキテクチャを学習用としてPublicに公開することを想定して、社内情報などのセンシティブ情報が含まれていない形になっているかレビューするスキル

  # レビューポイント
  - プロジェクトIDやプロジェクト名などの情報が含まれていないか
  - kaoやkaodbcなどの会社が分かる情報が含まれていないか
  - 個人名やメールアドレスなどの情報が含まれていないか
  - その他、社内情報などのセンシティブ情報が含まれていないか
  - 判断が難しい場合は、NGとしてユーザーに確認する
  - tfstateや.terraformフォルダや〜.lock.hclは勉強用のコードリポジトリとしてはコミットの必要がないので、念を入れて削除する
